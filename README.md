# KanbanBoardScheduler

## Постановка задачи

Канбан-доска задач для совместной работы. 

На доске три колонки (статусы задач): «К выполнению», «В работе», «Готово». 

Пользователь вводит имя, добавляет задачи, перетаскивает их между колонками и удаляет. Исполнителем задач становится тот, кто взял задачу в работу. Готовые задачи перемещать нельзя. 

Все, у кого открыта доска, сразу видят изменения и получают уведомления о действиях других пользователей. На странице также показывается, сколько пользователей сейчас онлайн.


В приложение добавлен планировщик задач Hangfire. Данные планировщика хранятся в СУБД SQLite (файл hangfire.db). Выполненные задачи можно посмотреть в консоли и в Hangfire UI (/hangfire, ссылка «Планировщик задач» на доске).

Задачи планировщика:

1. Разовая задача: при добавлении задачи на доску в консоль выводится сообщение о новой задаче.
2. Отложенная задача: если задача взята в работу и через 1 минуту всё ещё в работе, всем пользователям приходит напоминание.
3. Периодическая задача: каждые 12 часов из колонки «Готово» удаляются задачи старше 7 дней.
